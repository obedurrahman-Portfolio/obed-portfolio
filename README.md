# Mohammed Obed Ur Rahman — Portfolio

Personal ICT and ELV engineering portfolio, prepared for GitHub Pages.

## Files
- `index.html`: website content, styles, and mobile navigation.
- `Obed-Rahman-CV.pdf`: downloadable CV.
- `.nojekyll`: serves the site as static files.

## Editing
Edit `index.html` in GitHub to update text, projects, skills, or contact information.
To add a portrait, upload your photo and replace the initials block with an image.
Replace `Obed-Rahman-CV.pdf` to update the downloadable CV.

## Hosting
Enable GitHub Pages for the repository's main branch and root folder.
